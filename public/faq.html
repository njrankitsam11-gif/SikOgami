1. How does scan verification work?

Fold real paper following the 8-12 micro-step SVG (red valley, blue mountain, turn-over). Tap SCAN TO LEVEL UP, upload a phone photo. Frontend sends base64 to POST /api/verify {image, levelId, levelTitle}. With GEMINI_API_KEY set, Gemini 1.5 Flash returns {pass, score 0-99, feedback} generous at 75; without key, mock mode returns 88+ and always passes so you never get stuck. Even imperfect folds pass if effort shows.

2. What paper do I need? Can I use newspaper?

Any paper works — even newspaper — but good paper folds better. Level tips say exact: e.g., Tulip needs one 15×15cm pink Kami, Whale needs light blue, Penguin needs black/white duo. World 3 onward needs 2 papers (Tulip+Stem) up to World 5 Castle 12 papers. Curated packs: Toyo Kami Pastels 60 sheets ₹399, Oddy Washi 30 sheets ₹649, code SIK15 for 15% off at /#store.

3. How does admin unlock work?

Login with admin@sikogami.com / admin123 (seeded in Neon sikogami_users.is_admin). app.js:388 isUnlocked() returns true for all 30 if isAdmin(). Normal users unlock linearly progress.includes(id-1). Progress syncs via POST /api/progress {email, progress:int[]} to Neon sikogami_progress and merges with localStorage.

4. How does progress sync across devices?

On login, loadProgressFromNeon() GETs /api/progress?email= and merges via Set union sorted, prefers larger set, shows ☁️ Neon synced • n/30. On each saveProgress() it POSTs bulk. If offline, localStorage is source of truth, syncs when back online. No cookies, just Neon + localStorage.

5. Is Zen Mode different in dark mode?

Yes — style.css:60 zen-bg inverts: light #FDFBF7 / dark #0A0A0A, with .bg-white → #1A1A1A etc, so text stays visible. Zen has 4-6 Calm, 4-4 Balanced, 4-7-8 Deep patterns, timer 00:00, play/pause, and sound toggle (mock). All SVG paper colors use level color e.g., pink tulip, so you see the real paper.
